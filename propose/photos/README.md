# Photos folder

Drop your pictures of you and Royce in here using these exact filenames (JPG or PNG):

- `photo1.jpg`
- `photo2.jpg`
- `photo3.jpg`
- `photo4.jpg`
- `photo5.jpg`
- `photo6.jpg`

Any of them can be `.png` instead — just also update the `src` for that slot in `PHOTOS` near the top of the `<script>` in `../index.html`.

If a file is missing, the page shows a soft placeholder heart instead of a broken image, so it's safe to test the page before all six are in place.

Tips:
- Portrait or square photos (e.g. 4:5 or 1:1) look best in the gallery.
- Keep each file under ~2MB so the page loads quickly on her phone.
- You can also edit the caption text for each photo in the `PHOTOS` array in `../index.html`.
